# POLYLAB

Исследовательская платформа для поиска устойчивых рыночных закономерностей
на Polymarket. Это **не торговый бот** — это лаборатория, в которой гипотезы
проверяются до того, как к ним подпускают деньги.

## Отношение к Polybot

POLYLAB (PROJECT B) — полностью независимый проект. Polybot (PROJECT A)
продолжает работать отдельно со своим locked baseline, своим репозиторием,
workflow, Gist и Pages. Никакой общий код, состояние или конфигурация не
используются. Изменения здесь физически не могут повлиять на A.

## Принцип

Путь любой стратегии:

```
BACKTEST → OOS → SHADOW → FORWARD → PAPER → (только потом) LIVE
```

Правила, из которых проект вырос:

- Красивый результат, который держится на одном дне — это событие, а не edge.
- Мало данных — вывод `INCONCLUSIVE`, а не «работает».
- Hypothetical и realized не смешиваются нигде и никогда.
- Параметры не подбираются на out-of-sample и никогда — на forward.

## Режимы

| Режим | Что делает |
|---|---|
| BACKTEST | прогон по истории |
| SHADOW | генерирует сигналы, ничего не исполняет, считает hypothetical |
| PAPER | виртуальные сделки по реальным котировкам |
| TINY LIVE | зарезервировано, недоступно |
| LIVE | **отключён**, автоматического перехода нет |

Текущий режим: **SHADOW**.
