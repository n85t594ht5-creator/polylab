Решение по хранению

Схема «7 дней raw в Git» отвергнута по измерению: после удаления raw и gc --prune=now рабочее дерево уменьшилось с 49 до 27 МБ, а .git остался 45 МБ — объекты достижимы из истории. Прирост ≈ 3.2 МБ/сутки → ≈ 1.2 ГБ/год. Поэтому raw в Git не попадает вообще.
